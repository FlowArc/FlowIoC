# PointerControlsScreen

## Purpose
The WorldPointer test scene's buttons as a screen on Layer_5: Register, Change content, Hidden,
Close / open screen, Unregister All, and the target count. Presses leave on its Outgoing; the test
module answers.

## Concepts
world pointer sample, sample controls, test buttons, control panel

## Decisions
- **A screen, not a canvas in the scene.** An overlay canvas exists only through the ScreenManager,
  and a test scene uses it wherever it can, so the buttons that used to sit on a free `HudCanvas`
  are this screen.
- **Editor-only**, like the sample screen beside it: every script under `#if UNITY_EDITOR`, loaded
  from Resources, prefab under the module's `Editor/Resources`. Listed on `WorldPointerTestRoot`
  only.
