# FirebaseAnalytics

## Purpose
The Firebase Analytics plug for the Analytics module: one provider behind `IAnalyticsProvider`,
listed on `AnalyticsServiceRoot` as a sub-context, compiled only when the Firebase Analytics SDK
is in the project.

## Concepts
firebase, firebase analytics, google analytics, GA4, consent mode, FLOWIOC_FIREBASE_ANALYTICS,
FirebaseAnalyticsProvider

## Using it
1. The Firebase Analytics SDK in the project, with its own setup done (`google-services.json`,
   `GoogleService-Info.plist`, the External Dependency Manager's resolve).
2. From the UPM tgz (`com.google.firebase.analytics` in the manifest) the assembly compiles by
   itself. From the `.unitypackage`, add `FLOWIOC_FIREBASE_ANALYTICS` to Scripting Define Symbols.
3. `AnalyticsServiceRoot` > Sub Context Types > Add > `FirebaseAnalyticsServiceContext`. Leave
   **AutoSetup** on (Add Sub Context ticks it): a Root runs a sub-context's Setup only when the
   entry says so, and an unticked plug never plugs, with nothing logged.

## Decisions
- **Compiles only under its define.** The analytics core never references an SDK; this assembly
  carries `defineConstraints: FLOWIOC_FIREBASE_ANALYTICS`, set by a version define on
  `com.google.firebase.analytics` at any version. Without the SDK the plug is simply not there,
  and a Root that still lists it reports `Context Type couldn't find!` at play.
- **Cut and reported, never silently rejected.** Firebase drops an event whose name is over 40
  characters or carries whitespace; the provider cuts to 40 / 40 / 100 / 25 and warns with the
  event's name, so the developer fixes the name.
- **Consent one to one.** `AnalyticsConsentVO`'s four flags are Google Consent Mode's four, so
  nothing is derived here.
- **Bool travels as 1 / 0.** Firebase parameters are strings, longs and doubles.
- **No internal signal holder.** The plug has one context and one provider; the holder Create
  Module writes for every module was removed, because nothing here dispatches.

## Known gaps
- Compiled against the Firebase Unity SDK 13.15.0 (HitNPoP's DLLs) in FlowIoC-local-test on
  2026-09-16; not yet run on a phone against a Firebase project.
- No `SetDefaultEventParameters`; a value every event should carry is a user property.
