# FacebookAnalytics

## Purpose
The Facebook App Events plug for the Analytics module: one provider behind `IAnalyticsProvider`,
listed on `AnalyticsServiceRoot` as a sub-context, compiled only when the Facebook SDK for Unity
is in the project.

## Concepts
facebook, meta, app events, FB.LogAppEvent, ActivateApp, advertiser tracking, LDU,
FLOWIOC_FACEBOOK_SDK, FacebookAnalyticsProvider

## Using it
1. The Facebook SDK for Unity in the project, its App ID in `FacebookSettings`.
2. `FLOWIOC_FACEBOOK_SDK` in Scripting Define Symbols - the SDK is a `.unitypackage`, so no
   version define can see it.
3. `AnalyticsServiceRoot` > Sub Context Types > Add > `FacebookAnalyticsServiceContext`. Leave
   **AutoSetup** on (Add Sub Context ticks it): a Root runs a sub-context's Setup only when the
   entry says so, and an unticked plug never plugs, with nothing logged.

## Decisions
- **Compiles only under a define the game sets.** Same reason as the Firebase plug; here the
  define is by hand, and the Help page says so as an Important note.
- **ActivateApp on init and on every regained focus.** The SDK asks for it on resume; the provider
  hooks `Application.focusChanged` once and never unhooks - it lives as long as the app.
- **No user properties.** Facebook app events have none; the call is ignored and reported once.
- **Consent derived from the four flags.** Auto-logging follows `AnalyticsStorage`, advertiser id
  collection `AdUserData`, advertiser tracking `AdPersonalization`, and Limited Data Use is set
  when `AdUserData` is denied - HitNPoP's mapping, spread over the four.
- **Editor skips FB.Mobile.** It exists only on a device; the user id and the consent flags log one
  line and return.
- **No internal signal holder.** The plug has one context and one provider; the holder Create
  Module writes for every module was removed, because nothing here dispatches.

## Known gaps
- Compiled against the Facebook SDK for Unity 18.0.1 (HitNPoP's DLLs) in FlowIoC-local-test on
  2026-09-16, `FB.Mobile.UserID` included; not yet run on a phone against an App ID.
