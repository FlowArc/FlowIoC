# LoadingOverlayScreen

## Purpose
The overlay a feature shows while it waits for its own data: a dimmed screen that blocks input, a
turning ring and one line of text.

## Concepts
overlay, spinner, blocker, waiting, LoadingOverlayScreenView

## Decisions
- **It fills from its own model**, the same way the fullscreen screen does, so a set that ended
  while the prefab was loading closes the overlay the moment it opens.
- **Layer 8**, under the fullscreen bar and over everything a feature opens below.
- **No cancel.** Whoever began the Overlay set decides when it ends; the overlay only shows and closes.

## Known gaps
- No fade; a game adds one in the prefab it owns after install.
